# Prompt Clone Interactive Website

Create a modern, highly polished interactive website based as closely as possible on the visual reference I provide.

## GOAL

Recreate the reference website's overall visual experience, layout, spacing, typography, interactions, animations, and responsive behavior.

It should feel like a premium production website, not a generic template.

## TECH STACK

- React
- TypeScript
- Tailwind CSS
- Framer Motion for animations
- Lucide icons
- Fully responsive for mobile, tablet, and desktop

## DESIGN REQUIREMENTS

- Analyze the reference carefully before coding.
- Match its visual hierarchy and composition.
- Use a clean modern UI with precise spacing.
- Maintain consistent border radius, shadows, typography, and component sizing.
- Avoid unnecessary gradients unless they exist in the reference.
- Avoid making the design look like a generic SaaS landing page.
- Use smooth transitions and subtle micro-interactions.
- Make the mobile version equally polished.

## INTERACTIONS

- Smooth scrolling.
- Animated section entrances while scrolling.
- Hover and tap interactions.
- Smooth button states.
- Interactive cards/elements where appropriate.
- Use subtle parallax or motion effects only if they fit the reference.
- Animations should feel smooth and premium, not excessive.

## RESPONSIVE BEHAVIOR

### Desktop

- Preserve the composition and whitespace of the reference.

### Tablet

- Adjust columns and spacing naturally.

### Mobile

- Optimize specifically for portrait smartphone screens.
- Stack content intelligently.
- Keep important interactive elements easy to reach.
- Do not simply shrink the desktop layout.

## VISUAL QUALITY

The final result should look extremely close to the supplied reference, including:

- Layout
- Component proportions
- Typography scale
- Whitespace
- Colors
- Borders
- Shadows
- Background treatment
- Buttons
- Cards
- Navigation
- Animations
- Overall visual mood

## IMPORTANT

Do not redesign the reference into your own style.

Treat the supplied reference as the primary source of truth.

First identify:

1. Page structure
2. Main sections
3. Visual design system
4. Typography hierarchy
5. Navigation behavior
6. Interactive elements
7. Scroll animations
8. Mobile behavior

Then implement the complete website.

Use realistic placeholder content only when the original content cannot be determined.

The final website must be functional, responsive, visually polished, and ready to run.
