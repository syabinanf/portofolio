# Project Instructions

## Objective
Recreate the supplied reference website as closely as possible.

## Stack
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Rules
- Analyze reference images before coding.
- Match spacing, typography, layout, colors, and animations.
- Do not create generic SaaS UI.
- Prioritize visual similarity.
- Make everything responsive.
- Do not stop at a static mockup.
- All buttons and interactions must work.

## Workflow
1. Analyze reference.
2. Identify page sections.
3. Create reusable components.
4. Implement desktop layout.
5. Implement responsive mobile layout.
6. Add animations.
7. Compare implementation against reference.
8. Fix visual differences.
